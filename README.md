# fase4_componentepractico

**Prácticas simuladas**

## Descripción del proyecto

En este proyecto desarrollé un sistema integral en Python orientado a objetos para la gestión de clientes, servicios y reservas para una empresa ficticia llamada Software FJ. El objetivo principal fue aplicar los conceptos fundamentales de la programación orientada a objetos junto con el manejo avanzado de excepciones, garantizando la estabilidad y robustez del sistema ante posibles errores.

## ¿Qué se aplica en el código?

Durante el desarrollo del sistema apliqué los siguientes conceptos:

* Programación orientada a objetos (POO): abstracción, herencia, encapsulación y polimorfismo.
* Creación de clases abstractas y clases derivadas.
* Uso de métodos sobrecargados para el cálculo de costos.
* Implementación de excepciones personalizadas para el control de errores.
* Uso de estructuras `try`, `except`, `else` y `finally`.
* Registro de errores mediante un archivo de logs.
* Manejo de listas para almacenar la información sin utilizar bases de datos.

## Funcionalidad del sistema

El sistema permite gestionar de manera simulada los siguientes procesos:

* Registro de clientes con validación de datos.
* Creación de diferentes tipos de servicios (salas, equipos y asesorías).
* Generación y gestión de reservas.
* Procesamiento de reservas con cálculo automático de costos.
* Cancelación o confirmación de reservas según el resultado.

Además, el sistema incluye un menú interactivo que permite al usuario realizar operaciones en tiempo real, facilitando la interacción con la aplicación.

## Pruebas y simulación

Para validar el correcto funcionamiento del sistema, realicé una simulación con más de 10 casos, incluyendo:

* Datos válidos e inválidos de clientes.
* Creación correcta e incorrecta de reservas.
* Manejo de errores sin detener la ejecución del programa.

También implementé pruebas automáticas para verificar el comportamiento del sistema ante situaciones críticas.

## Robustez del sistema

Uno de los aspectos más importantes del proyecto es la capacidad del sistema para manejar errores sin fallar. Cada excepción es controlada adecuadamente y registrada en un archivo de logs, lo que permite llevar un seguimiento de los errores ocurridos durante la ejecución.

## Tecnologías utilizadas

* Python 3
* Programación orientada a objetos
* Manejo de excepciones

## Conclusión

A través de este proyecto logré desarrollar una aplicación funcional y estable que simula un entorno real de gestión empresarial, aplicando buenas prácticas de programación y garantizando un manejo adecuado de errores, lo cual es fundamental en el desarrollo de software profesional.
